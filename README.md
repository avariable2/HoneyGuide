# AI Engineering Portfolio · Native Apps · Privacy-First AI

I build native applications and practical AI systems, with an emphasis on privacy, document intelligence and reliable user-facing workflows.

## Featured public projects

### [HoneyGuide](https://github.com/avariable2/HoneyGuide) — Private-by-default document assistant for macOS
SwiftUI • Ollama • locally hosted LLMs • SQLite FTS5/BM25 • Apple Vision • PDFKit

An assistant that answers questions about explicitly selected local documents. It combines constrained read-only tools, source-linked answers, OCR and resource-bounded document indexing. Optional cloud-model mode has clearly documented privacy trade-offs.

**[Explore HoneyGuide's technical documentation](HONEYGUIDE.md)** · [Source code](https://github.com/avariable2/HoneyGuide/tree/main/Sources)

### [Bordero (iOS)](https://github.com/avariable2/Bordero_Swift) — Business workflow software
SwiftUI • Core Data • document/PDF workflows

Native application for managing clients, billing documents and status tracking. Demonstrates how to translate everyday business needs into usable software.

### [TokenTextField](https://github.com/avariable2/TokenTextField) — Reusable UI component
SwiftUI

A compact SwiftUI text-entry component for token/tag-style input.

## AI for real-world work

I am interested in helping small businesses and independent professionals integrate AI into everyday workflows: document search, administrative tasks, information retrieval and carefully scoped automation.

## Technical interests

Native Apple development (Swift, SwiftUI, Core ML), LLM integration and tool calling, retrieval pipelines, document extraction, practical workflow automation, and full-stack delivery.

## What I care about

- Grounding answers in verifiable sources rather than generating unsupported claims.
- Clearly separating on-device and cloud processing.
- Minimizing access to sensitive user data.
- Making AI tools usable and understandable by nontechnical people.

**Security note:** This portfolio deliberately omits credentials, client records, private datasets, sensitive business logic, and production infrastructure configuration. Private work is described at a high level only.
